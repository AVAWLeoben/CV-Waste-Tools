CV Waste Studio v14 — Recall@Precision saved results and shareable report
======================================================================

03 Precision / recall

* "Food class" is now labelled "Target Class". The internal JSON field
  `food_class` remains unchanged for compatibility with existing saved caches.
* "Open saved test..." at the top of the evaluation form reopens any completed
  `precision_recall_*` folder that contains `operating_point_summary.json`.
  This only reads saved files; it does not start model inference.
* The "Previous evaluations" dropdown (lower in the form) lists recent
  completed tests from the currently selected Results and cache folder.
  Press Refresh after manually editing that folder path.
* Every successfully completed evaluation attempts to save a summary graphic:

  Results and cache folder/
    precision_recall_YYYYMMDD_HHMMSS_ffffff/
      operating_point_summary.json
      food_precision_recall_by_confidence.csv
      evaluation_summary.png   <-- NEW

  This is the same results folder shown by the activity log and opened by
  "Open Results Folder". The graphic is generated by Pillow (a dependency
  provided by Ultralytics), and shows the target precision, measured precision,
  recall, confidence threshold, TP / FP / FN, model, class and confidence sweep.
* "View graphic" previews the saved PNG directly from within CV Waste Studio.
* Opening an older result without `evaluation_summary.png` automatically creates
  the report from that result's saved JSON and CSV where available; it does not
  modify the original JSON or rerun model inference.
* Existing metrics, CSV, cache format, NMS settings, cancellation, training,
  tuning, model comparison and other tools are unchanged.

Notes
-----
If drawing the PNG fails, the evaluation results are still saved and a warning
is printed in the activity log. The plotted confidence sweep is generated from
recorded raw threshold values; old runs without a CSV display the metric cards
and explain why the curve is unavailable.

Tests: `python -m unittest discover -s tests -q`
Syntax: `python -m py_compile test_model_recall_at_precision.py recall_report.py`
